# Contributing

Mark evidence as **Confirmed**, **Strongly evidenced**, or **Hypothesis**. Do not commit original Bubl firmware without redistribution rights, private imagery, or unique credentials. Hardware reports should include firmware/revision and measurement method. Destructive/update/erase operations must never be default behavior in tools.

Suggested repository topics for maintainers: `bublcam`, `360-camera`, `reverse-engineering`, `hardware-preservation`, `spherical-camera`, `fisheye`, `panorama`, `open-spherical-camera`, `embedded-linux`.
